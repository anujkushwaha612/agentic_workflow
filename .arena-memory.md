## Lessons now encoded in code+tests (do not relearn the hard way)
1. `edit_file` with no match must be `refused`, not `ok=False`; refused calls carry `path` and a
   repeated identical call is `REFUSE_REPEATED_REFUSAL` without re-execution.
2. An agent may only conclude from a read made **after** the last mutation of that path
   (`_already_read`/`_read_of` compare indices via `_last_mutation_at`).
3. Marker form: `    <stmt>  # ARENA-BUG: why. ARENA-FIX: <whole replacement stmt>`; replacement =
   `indent + fix text` exactly (no `#`-prefix splicing, no separate-line fix comment) — a *successful*
   write of an unparseable file is worse than a refused edit.
4. `list_files` with no prefix walks the agent's **read allocation**; `""`/`"."` at the root is
   refused for writes. Never make an agent escalate by handing it a call the jail must refuse.
5. `WAIT` only on conditions the runtime agrees are missing (compare `consumes` vs
   `consumed_ready`); parking on a satisfied artifact deadlocks the task.
6. `Outcome.data` keeps JSON scalars only — put `path` there or the agent cannot line a read up.
7. Empty verification != passed verification: `verify` requires tasks + re-run commands; `--version`
   prints runtime + python; `raise SystemExit(str)` maps to 64, not 1.
